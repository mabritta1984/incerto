# Incerto 0.1.0 — bifurcação da Jazida: especialista em investimentos à la Taleb — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nascer o repositório `incerto` com o corpus do Taleb em grafo (extração pelo `mineiro`, portão do PO, equação como nó com fiscal algébrico SymPy × Wolfram), dados do mercado brasileiro reproduzíveis e uma estação `taleb` que diagnostica fragilidade de exposições com cada afirmação marcada pela fonte.

**Architecture:** Repositório autônomo que copia da `Lastro` só o núcleo (Query API, credencial, embedding Vertex), o portão de onda, o recorte verbatim, o verificador frio, o injetor de regras e o padrão de testes/CI; nada de QUDT nem de dimensional. O pipeline é `originais/TALEB/` → `mineiro` → `conferir_onda` → `recortar_trechos` → `ingerir_trechos` → `extrair_equacoes` (staging em JSONL) → `fiscal` (SymPy no script, Wolfram pelo agente, as duas têm de bater) → `aprovar_onda` (MERGE no Aura, `corpus: 'incerto'`). Sobre isso, `dados_br.py` (SGS + COTAHIST, cache) alimenta `caudas.py` e `convexidade.py`, que a estação `taleb` usa para o relatório por ativo; o MCP `consulta_incerto` lê só o aprovado.

**Tech Stack:** Python 3.10–3.12 só biblioteca padrão, exceto `sympy==1.14.0` (+ `mpmath==1.3.0`, `antlr4-python3-runtime==4.11.1`) isolado em `extrair_equacoes.py` e `fiscal.py`; Neo4j 5 pela Query API (AuraDB em produção, `neo4j:5` no CI); Vertex AI `gemini-embedding-2` endpoint `global`; Wolfram pelo MCP do agente; `gcloud` para o bucket; GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-04-incerto-bifurcacao-da-jazida.md` (neste repositório `Lastro`; a Task 1 copia spec e plano para `incerto/docs/superpowers/`).

- Nome do plugin e do repositório: `incerto`; versão nasce `"0.1.0-dev"`, bump para `"0.1.0"` só na Task 20 (decisão A1).

- **Escritor único**: só `aprovar_onda.py` e `ingerir_trechos.py` escrevem no grafo; todo nó e toda aresta levam `corpus: 'incerto'` (decisão A4).
- **Nada sem fonte**: todo nó e toda aresta curada citam `(documento, topico)` dos `conferidos/`; aresta derivada leva `origem: 'derivada'` e o script.

## Review Focus

1. **Resposta do SGS com `valor` em string e data `dd/mm/aaaa`** (`{"data":"01/09/2026","valor":"0.055131"}`): o leitor devolve `(date, float)`; código inexistente devolve erro legível, não lista vazia → teste em Task 12.
2. **COTAHIST com cabeçalho (`TIPREG 00`), rodapé (`99`) e preço com duas casas implícitas**: `PREULT` `0000000003250` lê como `32,50`; linhas 00/99 são ignoradas sem exceção → teste em Task 12.
3. **Série com zeros e retornos negativos no Hill**: o estimador trabalha sobre `|perdas|` ou `|ganhos|` conforme a cauda pedida e descarta zeros antes do `ln`; nunca `ValueError: math domain error` → teste em Task 13.
4. **LaTeX com `\mathbb{E}[X]`, `\Pr`, `\mathrm{d}x`** (frequentes no Taleb): `\mathbb{E}[X]` normaliza para a função `E(X)`; `\Pr` e `\mathrm{d}` que não parseiam viram ⚠️ com o LaTeX preservado, nunca símbolo inventado → teste em Task 8.
5. **Parâmetros fora do domínio** (`kelly(p=1.2, b=1)`, `kelly(p=0.5, b=0)`, `barbell(fracao_segura=1.5)`): `ValueError` com a mensagem nomeando o parâmetro, nunca fração negativa silenciosa → teste em Task 14.
